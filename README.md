## About

I design and build production-oriented backend systems with a focus on software architecture, deterministic analysis, and developer tooling for the AI era.

My interest is in systems that are explainable, traceable, and built around clear architectural boundaries — not systems that work by accident.

---

## Areas of Focus

| Area | What I work on |
|---|---|
| **Software architecture** | Designing systems around explicit boundaries and responsibilities |
| **Architecture-aware tooling** | Static analysis and developer tools that reason about real architecture |
| **Deterministic systems** | Engines and analyzers that produce reproducible, evidence-backed output |
| **AI and code** | The gap between AI coding assistants and architectural understanding |
